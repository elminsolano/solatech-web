# Solatech Web

Sitio web corporativo de Solatech Group.

## Desarrollo Local

```bash
npm install
npm run dev
```

## Deployment a Vercel

1. Conectar repositorio a Vercel
2. Root Directory: `.` (raíz)
3. Framework Preset: Next.js
4. Build Command: `next build`

## Notas

- El archivo `vercel.json` es necesario para que Vercel detecte Next.js correctamente
- No modificar la estructura de directorios sin actualizar este archivo
